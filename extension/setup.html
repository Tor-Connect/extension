If macOS blocks the setup app

          
Open it once, then go to Apple menu → System Settings → Privacy & Security. Under Security, choose Open Anyway next to Tor Connect Setup and open the app again.

          
Only continue if you downloaded it from the official Tor Connect release.

        

        

          
Windows blocked the setup app

          
If SmartScreen appears, click More info, then Run anyway. Continue only if you downloaded Tor Connect Setup from the official Tor Connect release.

        

        

          
The Linux installer won’t open

          
Tor Connect’s Linux setup package is for Debian or Ubuntu on x64. Open the downloaded .deb file with your system’s software installer.

        

        

          
macOS says “Permission denied”

          
Verify the Tor bundle came from the Tor Project and check its signature. If it is verified, remove the quarantine flag from the installed copy in Terminal:

          
xattr -dr com.apple.quarantine "$HOME/Library/Application Support/TorChrome/runtime/bundle"

          
This removes quarantine only from this Tor bundle; it does not disable Gatekeeper globally.

          Tor Project signature verification instructions ↗
        

        

          
PowerShell says scripts are disabled

          
Allow scripts for this PowerShell window only, then run the setup command again:

          
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned

        

        

          
Permission denied in Terminal

          
Run the copied command in your own Terminal window. The manual setup script installs the helper in your user folder and does not need administrator access.

        

        

          
Why is a separate setup app needed?

          
Browser extensions cannot install or start Tor on their own. The setup app installs Tor on this computer and connects it to your browser.
