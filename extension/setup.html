If macOS blocks the setup app

Apple hasn’t notarized Tor Connect Setup, so macOS may block it.

  1. Try opening Tor Connect Setup once, then close the warning.
  2. Open Apple menu → System Settings → Privacy & Security. Under Security, click Open Anyway next to Tor Connect Setup.
  3. Confirm, then open Tor Connect Setup again.

Only continue if you downloaded it from the official Tor Connect release.

Why is a separate setup app needed?

Chrome extensions cannot install or start Tor on their own. The Tor Connect setup app installs Tor on this computer and connects it to the extension.

If macOS says “Permission denied”

First verify that the Tor bundle came from the official Tor Project and verify its signature. If it is verified, remove the quarantine flag from the installed copy in Terminal:

xattr -dr com.apple.quarantine "$HOME/Library/Application Support/TorChrome/runtime/bundle"

This removes quarantine only from this Tor bundle; it does not disable Gatekeeper globally.
