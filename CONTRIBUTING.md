# Contributing

Thanks for helping improve Tor Connect.

## Report a bug

Open a GitHub issue with the operating system, Chrome version, Tor Connect version, setup method, and steps to reproduce the problem. Include only the details needed to understand it.

Issues and contributions are public. Before posting, remove bridge lines, private IP addresses, usernames, local file paths, and other identifying or sensitive information from logs and screenshots. Your Git commit name and email may also be visible; check them before submitting a pull request.

## Submit a change

Open a pull request that explains what changed and how you checked it. Keep changes focused, and do not include generated installers or private runtime data.
